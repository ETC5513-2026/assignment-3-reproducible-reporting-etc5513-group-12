### Topic
Analysis of pedestrian movement patterns across Melbourne CBD during 
summer 2025–26, using data from the City of Melbourne Pedestrian 
Counting System.

### Requirements

This project requires [XQuartz](https://www.xquartz.org/) to be installed 
on macOS for rendering certain graphics. Please download and install it 
before running the report.

### Data

The raw data file is too large to store directly in the repository and has 
been provided as a zipped file. Before rendering the report or slides, 
please follow these steps:

1. Download the zip file from the repository
2. Unzip it
3. Place the CSV file inside the `data/` folder so the path looks like:
`data/pedestrian-counting-system-monthly-counts-per-hour-2.csv`
